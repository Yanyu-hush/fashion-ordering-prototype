# AxHub 导入说明

## 页面

- `home.html`：订货首页
- `catalog.html`：商品列表
- `product.html`：商品详情与颜色尺码配码
- `cart.html`：订货车
- `checkout.html`：确认订单
- `profile.html`：我的资料
- `index.html`：默认跳转到订货首页
- `overview.html`：六个页面的桌面总览，仅用于整体查看，不用于 AxHub 导入

## 推荐导入方式

1. 使用本地静态服务器打开本目录。
2. 在 AxHub 中逐个导入 `home.html`、`catalog.html`、`product.html`、`cart.html`、`checkout.html`、`profile.html`。
3. Axure 页面尺寸设为 `390 × 844`。
4. 导入后检查字体和图片，再补充页面跳转热区。

## 独立页面地址

AxHub 请逐个导入以下页面，不要导入 `overview.html`：

- `home.html`
- `catalog.html`
- `product.html`
- `cart.html`
- `checkout.html`
- `profile.html`

页面主要使用普通 HTML 元素、固定尺寸和本地 PNG 图片，避免复杂 Canvas、SVG 滤镜和前端框架，以提高转换稳定性。
